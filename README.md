
８（LoopRoom）

宿の一室で目覚め続ける、異変探しループ型ホラー。

## ルール
- 異変があると思ったら **ベッドで眠る**、ないと思ったら **ドアから出る**
- **8回連続**で正解するとクリア。間違えると1泊目に戻る
- 操作：WASD / 矢印キーで移動、マウスで視点、E / クリックで調べる

## 必要環境
- Unity 6（URP推奨）
- Input System パッケージ（Active Input Handling を *Input System Package* か *Both* に）
